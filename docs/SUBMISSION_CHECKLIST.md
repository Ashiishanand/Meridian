# Meridian Submission Checklist

## Repository
- Repository: https://github.com/Ashiishanand/meridian
- Default branch: `main`

## Before submission
1. Confirm the latest source files are committed and visible on GitHub.
2. Run the application from the repository root and verify login/dashboard.
3. If claiming goal/task management as complete, create, edit, and delete a goal and task and verify the changes persist in MySQL. The current README records these workflows as incomplete until verified.
4. Verify the Admin panel with an ADMIN account and confirm the user listing/report screen opens.
5. Never commit database passwords, real user data, or local IDE/build files.

## Suggested evidence screenshots
Save screenshots of the actual running application (not mockups) in a local `submission-screenshots` folder:
- `01-login.png`: login/register window.
- `02-dashboard.png`: dashboard after login.
- `03-admin-panel.png`: admin overview/user list.
- `04-goals.png`: goal screen only if implemented and tested.
- `05-tasks.png`: task screen only if implemented and tested.
- `06-mysql-schema.png`: MySQL Workbench showing the schema/tables.

## Important accuracy note
Only include screenshots of the real application as proof. Any illustrative UI mockup in a presentation must be labelled as a concept, not as a captured application screenshot. Describe unimplemented features as future work rather than completed functionality.
